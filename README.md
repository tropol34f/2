# Хрущёвки-85 — версия для Windows (.exe)

Игра в окне Electron. F11 — полный экран.

## Как получить .exe без установки программ
1. Создайте репозиторий на github.com и загрузите в него содержимое этой папки (включая скрытую папку `.github`).
2. Откройте вкладку Actions → «Build EXE» → дождитесь зелёной галочки (3–5 минут).
3. Скачайте артефакт `khrushchevki85-exe` — внутри `Khrushchevki85.exe`. Устанавливать его не нужно, достаточно запустить.

## Или локально (нужен Node.js)
    npm install
    npm start        # запуск в окне
    npm run dist     # сборка dist/Khrushchevki85.exe
